# Minimal Wi-Fi over LoRa
> Исследовательский проект по передаче веб-контента и других данных через LoRa с использованием собственного протокола, предварительной обработки и сжатия информации.

> Кликбейтное название, но я ничего лучше не придумал

> Первое название проекта: **Minimal Wi-Fi over Radio**

> Проект находится в активной разработке. Архитектура, протокол и используемые алгоритмы могут меняться.


## Цель проекта
Цель проекта — не создать очередную альтернативу Wi-Fi или мобильному интернету, а исследовать, насколько далеко можно зайти, если грамотно предварительно обработать данные, сжать их и передавать через крайне ограниченный радиоканал.

Практическая ценность подобного решения весьма специфична. В большинстве случаев существуют более подходящие технологии. Однако сам процесс исследования, разработки собственного протокола и поиска способов эффективной передачи данных представляет самостоятельный интерес.

> **P. S.** Автор знает о существовании Wi-Fi HaLow, NB-IoT и других технологий беспроводной связи. Просто ему стало интересно поработать именно с LoRa и самостоятельно реализовать весь процесс передачи данных — от формирования запроса до получения результата.

## Архитектура системы

### Путь прохождения данных
Пользователь формирует запрос в Android-приложении. После этого приложение отправляет его по BLE (Bluetooth Low Energy) на ESP32.

ESP32 принимает запрос и передаёт его по LoRa через радиомодуль, подключённый к контроллеру по UART.

Linux Server принимает пакет, проверяет контрольную сумму и наличие дубликатов. Если проверка пройдена успешно, пакет передаётся на обработку: расшифровывается payload и определяется тип запроса. Например, если payload содержит URL, сервер понимает, что клиент ожидает содержимое веб-страницы.

После формирования ответа сервер разбивает данные на небольшие фрагменты (чанки), формирует из них пакеты и последовательно отправляет их через LoRa.

Клиентский ESP32 принимает пакеты, проверяет контрольные суммы и передаёт их по BLE в Android-приложение.

Android-приложение собирает полученные пакеты, проверяет их, обрабатывает полученные данные и формирует итоговый ответ для пользователя.

### Компоненты системы

Весь проект состоит из трёх отдельных компонентов, каждый из которых имеет собственный репозиторий.

- **[Android Application](https://github.com/paranoik1)** — приложение на Kotlin, выступающее пользовательским интерфейсом системы. Отвечает за формирование запросов, взаимодействие с ESP32 по BLE, сборку полученных пакетов и отображение результата.

- **[ESP32 Client](https://github.com/paranoik1)** — прошивка на C с использованием ESP-IDF. Выступает промежуточным узлом между Android-приложением и сервером, обеспечивая передачу данных между BLE и LoRa.

- **[Linux Server](https://github.com/paranoik1)** — серверная часть на Python, размещаемая в домашней сети. Отвечает за получение запросов, обработку веб-контента, сжатие и передачу сформированных ответов клиенту.
